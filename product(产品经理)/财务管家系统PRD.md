## 一、项目概述

### 1.1 产品背景

随着个人财富增长和金融产品多样化，普通用户面临账户分散、收支不清、资产配置盲目、财务目标模糊等痛点。现有财务管理工具要么功能单一（仅记账）、要么门槛过高（专业投顾）、要么数据孤岛（各平台无法互通）。

**财务管家系统**定位为**个人/家庭的一站式智能财务中枢**，整合多账户、智能记账、资产分析、财务目标规划和智能提醒，帮助用户实现"看得清、管得好、规划明"的财务自由。

### 1.2 产品目标

- **C端用户**：帮助用户全面掌握财务状况，培养健康财务行为，实现人生各阶段财务目标
- **商业目标**：通过 Premium 会员、理财导流、金融机构合作实现商业化变现
- **数据壁垒**：构建用户授权的脱敏财务数据资产，为后续金融科技服务奠定基础

### 1.3 核心价值主张

> **"你的财务，一目了然；你的目标，一步一步达成。"**

## 二、用户分析

### 2.1 目标用户画像

| 维度 | 描述 |
|------|------|
| **年龄** | 25-50 岁，主力人群 28-40 岁 |
| **收入** | 年收入 15 万 - 100 万 |
| **职业** | 城市中产、职场进阶人群、小微企业主 |
| **财务痛点** | 账户多、收支乱、存不下钱、不知如何配置 |
| **技术接受度** | 中高，能接受 App/小程序，有一定移动支付使用经验 |
| **财务知识** | 基础到中等，对复杂金融产品有学习意愿 |

### 2.2 典型用户场景

- **场景 A（收支管理）**：每月收到 3 张信用卡账单、2 个储蓄卡、1 个公积金账户，想在一个界面看清所有收支
- **场景 B（财务健康）**：月光族想知道钱花去哪了，年底盘点发现没存下钱
- **场景 C（目标规划）**：计划 3 年后买房、5 年后送孩子出国、20 年后退休，需要分阶段规划
- **场景 D（智能提醒）**：忘记还信用卡被罚息，不知道何时该调整资产配置

## 四、功能需求详述

### 4.1 账户管理（P0）

#### 4.1.1 支持账户类型

| 类型 | 示例 | 数据来源 |
|------|------|----------|
| 银行卡 | 储蓄卡、信用卡 | 银行 API / 手动 |
| 投资账户 | 证券、基金、理财 | 券商 API / 手动 |
| 社保公积金 | 社保账户、公积金账户 | 政务 API / 手动 |
| 负债账户 | 花呗、借呗、房贷、车贷 | 手动录入 |
| 其他资产 | 房产评估、车辆、贵金属 | 手动估值 |
| 现金/钱包 | 微信钱包、支付宝 | 手动 |

#### 4.1.2 账户绑定流程

- **快速绑卡**：OCR 识别银行卡号，自动识别银行
- **安全验证**：银行卡四要素验证（姓名、身份证、银行卡号、手机号）
- **数据同步**：读取近 12 个月账单明细（储蓄卡流水、信用卡账单）
- **手动模式**：不支持 API 的账户，支持手动导入 / 每月对账

#### 4.1.3 账户安全要求

- 账户数据全程加密存储（AES-256）
- 金融机构 API 数据不留存原始数据，仅存储脱敏聚合数据
- 账户解绑一键清除本地及云端数据
- 支持生物识别（Face ID / 指纹）快速登录

---

### 4.2 智能记账（P0）

#### 4.2.1 记账方式

| 方式 | 说明 |
|------|------|
| **自动同步** | 绑定账户后，支出收入自动从银行流水生成记账条目 |
| **快速记账** | 首页快捷入口，一句话记账（"中午吃饭 85 元"→ 自动分类为餐饮） |
| **模板记账** | 周期性固定收支（房租、工资）可设置自动模板 |
| **拍照记账** | 拍照上传小票/发票，自动 OCR 识别金额和商户 |

#### 4.2.2 智能分类引擎

- 基于商户名称、MCC 码、金额等多维度自动分类
- 分类体系：一级类目（餐饮、居住、交通、购物、医疗、教育、娱乐、投资、工资、理财收益等）12 个；二级细类目 80+
- 用户可自定义分类映射规则，支持 AI 学习用户纠偏行为

#### 4.2.3 报销管理

- 标记可报销支出，设置报销对象/进度
- 报销状态追踪（待提交、已提交、已报销）
- 报销提醒（超时未报预警）

---

### 4.3 财务健康分（P0）

#### 4.3.1 评分维度

| 维度 | 权重 | 指标说明 |
|------|------|----------|
| 储蓄率 | 25% | 月储蓄金额 / 月收入，越高越好 |
| 应急储备 | 20% | 流动资产 / 月支出，达标值 3-6 个月 |
| 负债率 | 20% | 负债总额 / 资产总额，健康值 < 50% |
| 资产配置 | 20% | 分散度、投资与目标匹配度 |
| 收支平衡 | 15% | 月支出 / 月收入，警戒线 > 90% |

#### 4.3.2 健康分展示

- 综合分数：0-100 分，> 80 优秀，60-80 良好，< 60 预警
- 各维度雷达图：直观看到短板
- 改善建议：针对每项短板给出 1-2 条可执行建议

---

### 4.4 资产分析（P1）

#### 4.4.1 资产配置分析

- **按类型分布**：现金类、债权类、权益类、实物类、保险类
- **按流动性分布**：高流动性 / 中流动性 / 低流动性
- **按风险等级分布**：R1-R5 风险分布
- **对比参考**：显示同龄人/同收入水平的平均配置作为参考

#### 4.4.2 收益分析

- 支持时间段选择（近 1 月/3 月/6 月/1 年/自定义）
- 支持多账户收益叠加展示
- 支持 vs 大盘基准（沪深 300、中债指数）对比
- 支持基金/理财单品收益明细

#### 4.4.3 资产健康诊断

- 流动性风险预警（低流动性资产占比过高）
- 集中度风险提示（单一标的超 30% 提醒）
- 久期错配提示（长期投资匹配短期目标）
- 利率风险提示（固定收益产品在高利率环境下预警）

---

### 4.5 财务目标规划（P1）

#### 4.5.1 支持目标类型

| 目标类型 | 典型参数 |
|----------|----------|
| 购房计划 | 目标金额、目标时间、已筹备金额 |
| 子女教育 | 子女年龄、教育阶段、目标金额 |
| 养老规划 | 当前年龄、目标退休年龄、生活费需求 |
| 旅游计划 | 目标目的地、预算、时间 |
| 购车计划 | 车型预算、计划时间 |
| 通用目标 | 自定义名称、金额、时间 |

#### 4.5.2 目标分析引擎

- 根据目标金额、剩余时间、当前资产，自动计算每月需储备金额
- 模拟不同情景（保守/平衡/积极）下的目标达成概率
- 当目标偏离时，提供调整建议（延长周期/降低目标/增加月储）
- 目标进度可视化（倒计时、已完成比例）

#### 4.5.3 目标关联账户

- 可指定某一账户为"目标账户"，显示该账户与目标的关联进度
- 支持同一目标关联多个账户

---

### 4.6 智能提醒系统（P1）

#### 4.6.1 提醒类型

| 提醒类型 | 触发条件 | 通知方式 |
|----------|----------|----------|
| 账单到期 | 信用卡/贷款到期前 3 天/1 天 | 推送 + 短信 |
| 逾期预警 | 超过到期日未还 | 推送 + 短信 |
| 大额收支 | 单笔超用户设定阈值（如 5000 元） | 推送 |
| 目标偏离 | 月储备低于计划 20% 以上 | 推送 |
| 异常消费 | 某类目支出环比突增 > 50% | 推送 |
| 投资提醒 | 基金/理财到期、净值波动超阈值 | 推送 |
| 资产检视 | 每月末推送月度财务报告 | 推送 |

#### 4.6.2 提醒规则配置

- 用户可自定义每种提醒的开关、阈值、通知渠道
- 支持"免打扰时段"设置
- 支持智能聚合（同类提醒合并为一条）

---

### 4.7 家庭财务（P2）

#### 4.7.1 家庭成员管理

- 支持创建家庭，添加成员（配偶、子女、父母）
- 家庭成员可分别授权账户共享
- 家庭维度财务总览（家庭资产、负债、收支）

#### 4.7.2 家庭场景功能

- 共同目标（子女教育、买房）家庭成员共同储备
- 家庭记账（家庭公共支出分摊记账）
- 家庭成员财务隔离设置（隐私保护）

## 五、非功能需求

### 5.1 性能要求

| 指标 | 要求 |
|------|------|
| 首页加载时间 | < 2 秒（P95） |
| 账户数据同步 | < 5 秒（P95） |
| App 可用率 | ≥ 99.5% |
| 告警触达及时率 | ≥ 99% |

### 5.2 安全合规要求

- 符合《个人信息保护法》《网络安全法》《金融数据安全分级分类指南》
- 银行 API 数据不存储原始流水，仅存储聚合数据
- 密码/生物特征本地处理，不上传
- SOC 2 Type II 认证目标

### 5.3 兼容性要求

- iOS 14+ / Android 8+ 全量支持
- 微信小程序覆盖核心功能（账户管理、记账、提醒）
- 支持深色模式

### 5.4 数据迁移

- 支持从挖财、随手记、MoneyWiz 等主流记账工具导入数据
- 支持 CSV/Excel 模板导入
